# Third-party marks

Logos are trademarks of their owners and are used only to identify the services Kill Cord reads. Kill Cord is not affiliated with, sponsored by, or endorsed by any of them.

Corey decided on 2026-11-17 to show every provider's official mark next to its name, as identification (nominative use), and to accept the risk where a vendor's guidelines ask for permission first. Those vendors are flagged below so the decision can be revisited. On 2026-11-24 Corey confirmed it for every vendor here whose terms ask for permission first, or are unclear: keep their official marks as nominative use. That covers Anthropic, Google Cloud and Gemini, OpenAI, Cloudflare and Twilio, the batch 2 services fal and DeepSeek, and the manual presets Cerebras, Twelve Labs and Cohere.

Rules for a mark:

- Take the geometry from the vendor's own brand page, press kit, or site assets. Never redraw, distort, or add effects.
- Commit the vendor's file byte for byte where it is just the mark. Where the official file is a lockup (mark plus wordmark), the mark's paths are copied unchanged into a file of their own and the canvas is cropped to them. Both cases are noted below.
- Every file lives in `KillCord/Assets.xcassets/ProviderMarks/mark-<provider>.imageset` as a template image, so it draws in one colour, the panel's label ink (#161616 light, #E6E7E8 dark). A colour mark becomes the same shape in one colour.
- The provider's name always sits next to the mark, and the mark never suggests a partnership.
- The mark fills about half of its key, which leaves clear space. OpenAI's file includes its own clear space, so it draws 1.45 times larger, the same as in Fuel Gauge. Cloudflare's cloud is very wide, so it draws 1.3 times larger to stay legible. ElevenLabs' file is mostly clear space around its two bars, so it draws 2.8 times larger, and Apify's file has wide clear space, so it draws 1.45 times larger, as does Deepgram's at 1.5.
