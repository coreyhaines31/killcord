# Trademark policy

The Kill Cord code is licensed under the terms in [LICENSE](LICENSE). The **Kill Cord** name and app icon are not. They identify the official app, so people know what they're installing, which matters for an app you trust with billing keys.

## What's fine

- Saying your project works with, or is based on, Kill Cord.
- Using the name in articles, reviews, tutorials, and comparisons.
- Building and running Kill Cord from source for yourself or your team, unchanged.

## What needs a different name

If you distribute a modified version, give it its own name and icon. Don't call it Kill Cord, use the app icon, or present it as the official app.
