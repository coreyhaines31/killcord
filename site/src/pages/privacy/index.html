Privacy

Kill Cord needs your billing keys to read your spend. Here is exactly where they go, what it saves, and what it never sends.

Your keys

Kill Cord stores each provider’s key in your login Keychain under the service app.killcord.KillCord.providers, one item per connected account (you can connect more than one account of a provider). It sends each key only to that provider’s billing API, over HTTPS. Keys never appear in files, preferences, logs, error messages, or exports.

When you connect a provider, Kill Cord checks the key with the provider first, then saves it. Never paste a key into a chat or an AI agent to set Kill Cord up. If you already have, revoke it and create a new one.

Read only, and plain about key power

Kill Cord only reads billing. It never changes a provider setting, including caps: the caps audit opens the console page and you make the change yourself.

Some providers don’t offer a read-only key. No Anthropic key is read-only: a service account or personal key can do whatever its linked account’s role allows, and an admin key can also manage your organization, and Twilio and Neon have no read-only keys either. OpenAI may offer read-only admin keys; choose that if you see it. Kill Cord says this before you save a key. If a key leaks, revoke it in the provider’s console.

What it saves on your Mac

  • The last spend it read (amounts and times, no keys) in ~/Library/Application Support/Kill Cord.
  • Your alert thresholds, caps audit checkmarks, and a random id for each connected provider (no part of the key), in its preferences.

Requests use an ephemeral session, so nothing is cached to disk.

What goes over the network

  • Requests to each connected provider’s billing API, with that provider’s key.
  • The update check against Kill Cord’s releases on GitHub.

That’s all. The app has no telemetry, no analytics, no account, and no server of ours in between.

killcord.app

This website (not the app) uses the TracerKit tag manager to load Headstream and Fathom Analytics for visit analytics. TracerKit and Headstream set first-party cookies and browser storage with random visitor and session ids so they can tell new visits from returning ones; Fathom uses no cookies. No ad tracking, no personal data sold or shared. The site is static pages hosted on Vercel, which keeps standard server logs. Its fonts are served from this site, not from Google Fonts.

If you join the Kill Cord Teams waitlist, your email and your answers (company size, the APIs you pay for, anything you write, and the page that sent you) are stored by Kill Cord, along with your browser’s user agent and a one-way hash of your IP address that we use only to stop spam signups, and we email you through our email provider, PostShiba. We use them only to tell you about Teams, and every email has an unsubscribe link.

Removing everything

In Settings › General, click Remove All… to delete every key from the Keychain and all local data. If you deleted the app first, open Keychain Access, search for app.killcord.KillCord.providers, and delete each item. Removing keys from Kill Cord doesn’t revoke them, so revoke any you no longer need in each provider’s console.
